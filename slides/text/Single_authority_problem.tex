\begin{frame}{Multi-Authority Setup}

    Let's explain the setup for $n$-out-of-$K$ authorities:

    \vfill

    Each authority $k$:
    \begin{itemize}
        \item has a public identifier $x_k$
        \item generates a secret polynomial $f_k$ of degree $n-1$
        \item sends $f_k(x_{k'})$ to each authority $k' \in K$ 
        \item aggregates received values $y_k = \sum_{i \in K} f_i(x_k)$
    \end{itemize}

    \vfill

    Credential request:
    \begin{itemize}
        \item Client requires at least $n$ authorities to sign his destination $\Delta$ (i.e. $y_k \Delta$)
        \item Client aggregates into $y \Delta$ using Lagrange interpolation 
    \end{itemize}
\end{frame}
